ColonyV Owner's Manual

How to actually run the machine — and what every setting does.

Quick start — how to use it

  1. Sign in. The app is private. Enter your username and password on the login screen. A session lasts 24 hours. After 10 failed attempts in a row you are locked out for 15 minutes.
  2. Open Settings and check: your Active Focus Area topic, Brand Tone, Videos per run, and your RSS feeds. Press Save after each panel you touch.
  3. Go to Dashboard → click Run. The run starts immediately and the schedule arms automatically (see Scheduler below).
  4. Watch the workspace cards. Each video moves through 6 stages — they light in real time. Live Log shows every agent line.
  5. Wait for publish. When Publishing completes, the video is uploaded (public) to the connected YouTube channel, then the Analyst reviews the run in the background.

The 6 workspace stages are Monitor (discovery), Research (fact-check), Script, Art Director, Render (MP4), and Publish (upload). Cards turn green while a stage is running, go grey after publish, and reset for the next video. When you Pause or Stop, everything greys out.

Pipeline controls

ControlWhat it really does
RunStarts a new run with the saved settings (Videos per run stories). Also arms the scheduler: the countdown starts now.
PauseFreezes the current work mid-step and stops the timeout clock. Nothing advances while paused.
ResumeContinues exactly where Pause froze the run.
Stop CompletelyTerminates the whole process tree and marks the run stopped. It also disarms the scheduler — no more automatic runs until you click Run again.

Reference: every setting, explained

Pipeline Defaults
SettingWhat it does
Videos per runHow many stories are processed into videos each time you run (or each scheduled run). Range 1–20. Picked from the top-ranked stories discovered that run.
Maximum narration durationTarget cap (seconds, 10–60) for the voice track. The Scriptwriter keeps narration inside this window; the whole video is shorter than this only if the script is.
Auto-Run ScheduleHow often the machine fires autonomously. Options: 1 min / 5 min (test-only — useful to verify the scheduler), 1 h, 3 h, 6 h, 12 h, 24 h.
Scheduler behaviour: the schedule starts disarmed. It only begins counting after your first manual Run. From then on it fires every interval on its own. Stop Completely disarms it again.
AI Brain (Model)

Locked to Gemini on Vertex AI — no API keys needed; cloud credentials are handled automatically. The model id shown is read from the COLONYV_GEMINI_MODEL environment variable and is read-only here.

Channel Niche & Target Topic Focus
SettingWhat it does
Active Focus AreaPick the topic the channel will monitor and produce. During discovery the machine builds a live Google News search feed for this topic and scores stories for relevance to it.
+ Add Custom TopicAdd your own niche. Selecting it makes the pipeline chase that niche until you switch back.

RSS Feed Sources
ColumnWhat it does
URLThe RSS/Atom feed the Monitor scans. Products like Google News search links work too.
CategoryFree-text label (tech, hardware, crypto…) used for scoring context. Not a filter.
EnabledUnchecked feeds are skipped entirely.

How feeds are used: with an active topic, the topic’s news feed is searched first, then your feeds here act as backfill — so one dry feed never stalls a run. A feed that fails to load is skipped with a warning; the others still contribute.

YouTube OAuth Credentials

Paste the downloaded client_secret.json, press Save Credentials, then Connect with Google to authorize your channel. Disconnect revokes it. Videos from the publisher upload as public to the connected channel. If uploads fail you can retry them from the YouTube tab.

How a run flows (you don't have to do anything)

  1. Monitor — fetches the topic + your feeds, de-duplicates against stories already seen, and scores candidates.
  2. Research — reads each story, verifies every claim and records contradictions + confidence.
  3. Script — writes the hook/body/CTA using only verified claims.
  4. Art Director — designs the episode: palette, illustration style, per-shot plan.
  5. Visual Producer — narrates with TTS, generates illustrations, renders the 1080×1920 MP4.
  6. Publisher — uploads to YouTube with title, description, tags.
  7. Analyst — reviews the run and feeds learned signals back into future prompts.
Quality gates: a story with 0 verifiable claims or 2+ contradictions is not published — it's dropped and discovery looks for more candidates instead. You get fewer, correct videos rather than louder, wrong ones.

Logs, runs & costs

  • Live Log / Logs — every agent line streams over WebSocket and is saved to output/<run_id>/pipeline.log.
  • Past Runs — every run and story; click one for per-story detail.
  • Analytics — stories/day, scores, YouTube views, success rate.
  • Costs — LLM call counts and estimated spend per run.
